# senate-analysis

## Overview

The goal of this project is to examine the United States Senate and its problems, especially the discrepancy between its demographics and the demographics of the US as a whole.

Note: The most recent version of the site is not currently available except when run locally; I rewrote everything in React and hosted it on a site that has since shut down. While not quite as up to date, the static version of the site can be seen at <https://isabelle-sanford.github.io/senate-analysis/>. 

## About

This project was initially created as a group project during the USC Viterbi School of Engineering Data Analysis & Visualization Bootcamp, by Steven Brown, William Enriquez, Michelle Risucci, Isabelle Sanford, and Kosal Sieng. It has since been extended by Isabelle Sanford to its current state, including most of the words and citations, plus a complete rewrite in React. The site uses the Plotly library for its graphs. Further information and all sources can be found at <https://isabelle-sanford.github.io/senate-analysis/>.
